# Customer Purchase Prediction using ANN

##  Project Overview

Developed an **Artificial Neural Network (ANN)** model to predict whether a customer will make a purchase based on customer session and behavioral data. The project includes data preprocessing, feature encoding, scaling, ANN model development, optimizer comparison, and model evaluation.

##  Objective

* Predict customer purchase behavior using an ANN.
* Perform data cleaning and preprocessing.
* Compare **Adam and SGD optimizers**.
* Evaluate model performance using classification metrics.
* Analyze training and validation performance.

##  Technologies Used

* Python
* TensorFlow
* Keras
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Google Colab

##  Key Steps

* Loaded and explored the customer purchase dataset.
* Handled missing values using mean imputation.
* Removed duplicate records.
* Applied one-hot encoding to categorical features.
* Separated features and target variable.
* Split data into training and testing sets.
* Applied **StandardScaler** for feature scaling.
* Built and trained ANN models using Adam and SGD.
* Generated predictions using a 0.5 classification threshold.
* Evaluated the models using Accuracy, Precision, Recall, F1-Score, and Confusion Matrix.
* Compared Adam and SGD performance using accuracy.

##  Model

* Built an ANN using **TensorFlow/Keras Sequential API**.
* Hidden Layer 1: **64 neurons with ReLU activation**.
* Hidden Layer 2: **32 neurons with ReLU activation**.
* Output Layer: **1 neuron with Sigmoid activation**.
* Loss Function: **Binary Cross-Entropy**.
* Optimizers compared: **Adam and SGD**.
* Trained for **10 epochs** with validation split.

##  Result

* Successfully developed an ANN-based binary classification model for customer purchase prediction.
* Compared **Adam and SGD** optimizers based on model accuracy.
* Evaluated predictions using Accuracy, Precision, Recall, F1-Score, and Confusion Matrix.
* Visualized training and validation accuracy and loss to analyze model performance.
* The project demonstrated the complete workflow from data preprocessing to ANN-based prediction.
